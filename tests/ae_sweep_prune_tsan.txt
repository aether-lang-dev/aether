# Tests the TSan sweep (`make test-tsan`, #3542) leaves out of the part of the
# corpus it runs (tests/tsan_sweep_select.txt), as a fixed substring of the
# path, the way tests/ae_sweep_prune.txt is read. Each one checks something
# ThreadSanitizer replaces, so under it the test says nothing about the code;
# every one still runs on the other legs.
#
# One reason per entry, and it has to be about what TSan changes, not about a
# failure nobody looked at:
#   SANDBOX     confines a child through the sandbox's preload library. The
#               sweep builds that library with -fsanitize=thread too, and
#               clang links the TSan runtime only into executables, so a
#               child that is not instrumented (/bin/sh, a system tool) cannot
#               resolve the library's TSan calls when it loads it.
#   RSS         bounds the resident set, which under TSan holds its shadow
#               memory and the history of every thread.
#   CODE-SHAPE  reads the compiled code (inlining, vector instructions,
#               FORTIFY's abort, debug info, -Werror warnings), which TSan's
#               instrumentation and the sweep's -g -O1 change.
#
# Most of these are not picked by the select file today; they are listed so
# that a test that later starts an actor does not bring them in.
