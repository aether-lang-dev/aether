# cannot run, listed one per line ('#' and blank lines ignored). Linux CI

# What stops leaks(1) (#3202, seen with the gate's sample(1) of the stuck
# run): leaks --atExit interposes _exit in the target's image
# (libLeaksAtExit's my__exit), and the hook stops the exiting process for
# an inspection. A child the target forks has the same image. One that
# execs a program is fine, but one whose exec fails leaves by _exit before
# any exec, so the hook stops it too. leaks(1) inspects only its target, so
# that child stays stopped, and its parent's wait for it never returns. So a
# program that starts a missing program on POSIX cannot run under the gate.
# Keep such a case in a test of its own, as test_os_run_supervised_cannot_start
# does, and the rest of the program stays checked here.
test_os_run_supervised_cannot_start
