- **A closure kept in a struct field, a message field, a global or an actor's state is released when its holder lets go of it.** Each such slot holds a reference of its own to the closure's environment, as a struct owns its string fields: storing takes one (a fresh closure's is adopted, a view of one held elsewhere is retained), overwriting the slot or destroying the holder releases it, and copies (`b = a`, a struct passed or returned by value, `<Name>_dup`) retain. A fixed-size array field of such structs releases, replaces and copies every element; a message's closure field is released with the message once the handler is done; a local bound to a field read and a closure a function returns from a field hold references of their own. Before, `h = Holder { cb: build("a") }; h.cb = build("b")` kept both environments, with the cells and strings they captured, for the rest of the program (118 KB over 1000 rounds). A module-level `var name: fn = null` now starts as the zero closure instead of failing to compile.
