- **`xml` keeps a reference to an entity the document's DOCTYPE declares.** The reader checks references against the five predefined entities and refuses any other (#2510), but it does not read a DOCTYPE's internal subset, so `<!DOCTYPE d [<!ENTITY e "x">]><d>&e;</d>`, which is well-formed, was refused as an undeclared entity. When the internal subset declares entities, a reference to a name the reader does not know is kept as written; a document whose DOCTYPE declares none is still refused.
