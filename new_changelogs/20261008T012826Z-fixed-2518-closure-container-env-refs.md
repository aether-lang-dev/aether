- **A list or map that keeps a closure value holds a reference of its own to its environment.** `list.add(l, f)` handed the list the caller's single reference, so adding one closure twice, to two lists, or keeping it in a local past `list.free` freed the environment twice: an access violation. Each slot and each map entry now takes its own reference when a closure value is stored (`list.add`, `list.list_set`, `map.put`) and releases it when the element goes (`free`, `remove`, `clear`, an overwrite), and a list releases the strings it owns on `remove` and `clear` too, as the string list does. A closure literal or a handed-over closure stored directly is released by the store; a parameter stored into a container no longer counts as kept, so its caller frees its own reference.
