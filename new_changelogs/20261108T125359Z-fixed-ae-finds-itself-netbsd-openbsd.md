- **`ae` finds its compiler from any directory on NetBSD and OpenBSD.** It located itself through `/proc/self/exe` or FreeBSD's sysctl, neither of which these have, so outside its own tree a dev build (or a test changing directory) said "Aether compiler not found". NetBSD asks `sysctl(KERN_PROC_ARGS, KERN_PROC_PATHNAME)`; OpenBSD, which has no such query, resolves `argv[0]` against `PATH` at startup.
