- **A closure passed to an extern that uses it only during the call is released once the call returns.** An extern parameter can be declared `@noescape` (`extern string_seq_each(s: *StringSeq, f: @noescape ptr)`): the C function neither stores, frees nor hands the argument to another thread, so the compiler treats a closure passed there as it does for an Aether callee that keeps nothing, releasing a literal's environment right after the call and a local's at scope end, and builds the `ptr` slot's box on the caller's stack. An unannotated extern keeps today's behaviour (the environment lives on, since the callee may have stored it). The string seq combinators (`seq_each`, `seq_map`, `seq_filter`, `seq_reduce`, `seq_zip_each`), `fs.walk`, `string_list_sort` and the `std.mem` function-pointer shims carry it, and their C sides no longer free the box or the environment; before, a capturing closure passed to them leaked its captured cells and strings on every call (the C side freed the environment without running its destructor), and a closure local passed to `seq_each` twice used freed memory. Only valid on `ptr` and `fn` parameters.
