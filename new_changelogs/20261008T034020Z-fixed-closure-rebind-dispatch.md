- **A closure local rebound to a value the compiler cannot name is called through its current value.** `g = || { ... }` followed by `g = h.cb`, `g = f` (a parameter) or `g = pick(...)` still dispatched `call(g)` to the first literal, since only a rebinding to another literal made the binding ambiguous; it is decided at discovery now, so a rebinding later in a loop body is covered too.
