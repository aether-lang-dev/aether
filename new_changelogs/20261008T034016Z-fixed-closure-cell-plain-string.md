- **A plain heap string stored into a variable a closure writes is freed with it.** Such a variable lives in a shared cell that frees the refcounted strings it holds; a plain malloc'd buffer (an `@heap` extern's strdup, `os.getenv` among them) was stored as it was and never freed, since the cell cannot tell it from a literal. The store now turns it into a refcounted copy on the way in. The cell's reference count is atomic, as the closure env count already was: an env holding the cell can be released on a worker thread while the declaring scope releases its own reference.
