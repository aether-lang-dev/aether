- **`sandbox.spawn_socket(perms, prog, argv, env) -> (fd, pid, err)`: a sandboxed child with a socket (aether#3503).** It is `os.run_socket`'s channel (the child's fd 3, `AETHER_IPC_KIND=socket`) with `spawn_sandboxed`'s containment, held to `perms`, with a full argv and env (`spawn_sandboxed` takes one argument). It fails closed: on macOS, Windows and FreeBSD, or on Linux when the preload library or the kernel layer cannot be set up, it returns an error and starts nothing. Running a child uncontained is a separate, greppable call, `sandbox.spawn_socket_uncontained`. The grants travel on a sealed memfd the child keeps (`AETHER_SANDBOX_GRANTS_FD`), since the call returns before the child exits and so cannot remove a named shared-memory object. Also fixed: gcc `-Werror` builds stopped on `-Wformat-truncation` in the preload lookup.
