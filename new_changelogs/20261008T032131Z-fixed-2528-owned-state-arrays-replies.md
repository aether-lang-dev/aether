- **An actor's state, owned arrays, reply fields and a stored closure literal are released by their holders.** An actor now has a `destroy_state` hook (`ActorBase`, set by the generated spawn) that the scheduler runs exactly once when it ends a scheduler-owned actor, on a release or at teardown: each `string` state field is freed per its tracker, which is a field of the actor rather than a handler local (so a value stored by an earlier message is freed when a later one overwrites it; before, neither it nor the last value was ever freed), each closure field's environment is released and each owning struct field destroyed. A `string[N]` struct field owns a copy of every element and a `fn[N]` field a reference per element, released on destroy and on an element store, copied or retained by a copy; a local array of structs that own strings or closures destroys its elements at scope exit, replaces one on `arr[i] = v` and copies each on `other = arr`. A reply message's string and closure fields are the asker's: the field the ask reads out is taken, the rest released with the reply, and a closure reply (a field or an expression) now compiles and is owned by the asker's binding. A closure literal passed to a function that keeps it in a struct field, a message field, a global or state is released by the caller after the call, the holder having retained its own reference.
