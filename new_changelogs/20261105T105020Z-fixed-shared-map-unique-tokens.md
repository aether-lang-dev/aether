- **Two shared maps no longer get the same token.** A map's token, the guard a hosted language reaches the map through, came from the monotonic clock mixed with a stack address, so two maps made within one clock tick from the same call depth shared it (about half the time back to back on macOS): a lookup found the first map, and revoking the second's token revoked the first. Tokens now come from the OS random source (`getrandom`, `arc4random_buf`, `rand_s`), drawn again while any registered map holds them; `tests/runtime/test_runtime_shared_map.c` holds 2000 back-to-back pairs to it.
