- **A request line that is not method SP target SP version is refused (400) (#3666).** The parser took whatever lay between the spaces: a method that is not a token (`G@T`), an empty method or target, and a target holding a tab, a CR or another control byte, which the reverse proxy then wrote into the request line it sent upstream. The method is a token and the target has no control byte (RFC 9112 3); a target past ASCII is still taken. Found by the new HTTP head fuzzer (#3543).
