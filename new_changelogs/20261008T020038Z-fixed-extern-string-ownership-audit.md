- **Fourteen more externs that return a fresh string no longer leak it.** Every `extern ... -> string` in std and contrib was audited against its C body. Fourteen hand the caller a new buffer but were declared plain `-> string`, so the compiler treated the result as borrowed and never freed it: `tcp.read` (std.tcp's `tcp_receive_raw`, one buffer per read), `proxy.pool_metrics_text` (the whole metrics text per scrape), `sqlite.exec` (its error text), tinyweb's `ws_generate_accept_key`, `ws_base64_encode` and `ws_unmask` (one buffer per upgrade and per masked frame), `factor.eval`, `factor.get`, `racket.evaluate`, `racket.get`, `rhombus.evaluate`, `rhombus.get`, and the aether host's `capture_sandboxed` and `capture_script_sandboxed`. Each is declared `-> string @heap`; `tcp.read` hands its buffer over instead of copying it first. The other 134 return storage that their handle, a static or a thread-local slot owns, and keep their declarations.
