- **A callback passed to a function that only passes it on is released after the call, and `list.add(l, box_closure(f))` is the store `list.add(l, f)` is.** The callee-body walk decided a `fn` parameter passed on (`it(cb) { it_impl(cb) }`) was kept by its kind before reading the callee's body, so the env of every callback handed to such a wrapper lived for the rest of the program; a visible body now decides, as it does for every other argument. An explicit `box_closure` at a list or map store handed the container a raw pointer it did not know it owned, so neither box nor env was reclaimed; the container now takes its own reference and owns the box, and the local keeps its own.
