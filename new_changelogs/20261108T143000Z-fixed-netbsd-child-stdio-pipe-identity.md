- **On NetBSD and OpenBSD a spawned child no longer keeps another spawn's pipe as its stdout (#3209).** The child keeps fds 0-2 only while each is still the file it was at startup, compared by device and inode; both report every pipe as device 0, inode 0, so when the parent's stdout was a pipe, any pipe that took a closed stream's number passed for it. They now also compare the time the pipe was made (NetBSD's birth time, OpenBSD's change time).
