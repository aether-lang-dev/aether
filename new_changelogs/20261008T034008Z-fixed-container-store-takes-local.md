- **A list add or map put of a string local takes it as every other owning slot does.** On the local's last use its reference moves into the container; read again afterwards, the container gets a copy of what the local owns (or its own reference to what it borrows) and the local keeps its own frees. The store used to adopt the local's single reference and mark the local escaped, so a local stored twice, or stored in a loop, was freed once per store (an access violation), and a `string` parameter a closure keeps by storing it took a reference on entry that the raw store then left to nobody, a leak per call.
