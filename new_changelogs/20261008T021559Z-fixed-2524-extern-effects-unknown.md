- **A call the compiler cannot see is evaluated in source order (#2524).** An extern's effects are unknown: `pair(strbuilder.append(b, "xy"), strbuilder.length(b))` and `pair(map.map_put_raw(m, "k", m), map.map_size(m))` emitted both calls inline as C arguments, so gcc read the length and the size first (0, want 2 and 1), and an extern with state of its own and no handle parameter was read out of order the same way. A C extern, a C function pointer, a closure, a message send, and a function of the program that makes such a call are opaque now: an opaque call is evaluated into a temporary ahead of every later operand that calls anything, reads a module global or a variable shared with a closure, or reads memory through a pointer, a field or an index. Operands that read only plain locals and literals stay inline, beside a call or not. The `@mutates` extern-parameter mark that was meant to declare what an extern writes is gone: it could not narrow the rest of an extern's effects, so it bought nothing, and the std collections no longer carry it.
