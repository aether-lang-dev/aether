- **`std.intmap`: a hash map from `long` keys to `long` values.** `std.map`
  keys every entry by a string, so counting 4-grams meant rendering each one
  to text, hashing the bytes and comparing them with `memcmp`; that put the
  LangArena Distance::NGram benchmark at 26x Go. The new table hashes the
  integer itself and keeps key and value inline in an open-addressing array,
  and `intmap.add(m, key, delta)` counts an absent key from 0 in one probe.
  `keys` and `values` snapshot into `std.longarr` buffers.
