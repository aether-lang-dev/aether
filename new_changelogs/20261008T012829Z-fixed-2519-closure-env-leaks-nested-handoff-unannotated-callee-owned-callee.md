- **Three closure environments #2507 still leaked are freed.** An owned closure passed to a function with no declared result type is released after the call (the callee's definition says whether the call yields a value). An owned closure used directly as the callee, `call(make_counter())`, is evaluated once into a temporary and released after the call; it used to run the call twice and keep both environments. A hand-off inside a nested closure's body (`g = || { keep(f) }`) no longer keeps every environment the local was bound to: the body retains the environment for the new holder right before the hand-off, so the local and the capturing closure still free theirs, and a keeper that stores into a container takes its own reference.
