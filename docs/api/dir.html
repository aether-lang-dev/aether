List directory contents. Returns (DirList ptr, "") on success, (null, error) on failure. Caller must free the returned ptr with dir.list_free.

list_kind fn

list_kind(l, index) -> int

l: ptr, index: int

#966: file kind of entry `index`, straight from readdir's d_type — no stat(2) per entry. Same encoding as file_stat's kind: 1 = file, 2 = dir, 3 = symlink (target not followed), 4 = other; 0 = unknown (the filesystem didn't report a type — stat that entry to resolve it).
