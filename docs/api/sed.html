sed

std.sed — FreeBSD's sed (usr.bin/sed) as a library.

import std.sed

options fn

options() -> ptr

Default options: what `sed script` does with no flags.

options_free fn

options_free(op)

op: ptr

quiet fn

quiet(op)

op: ptr

-n: print only what the script prints.

extended fn

extended(op)

op: ptr

-E: Extended regular expressions.

separate fn

separate(op)

op: ptr

-s: each input file on its own: line numbers restart, $ is each file's last line, and the hold space and ranges reset, as -i treats files.

in_place fn

in_place(op, suffix)

op: ptr, suffix: string

-i suffix: edit the files run_files is given in place, one at a time (implies separate), keeping a copy of each as name + suffix unless suffix is "". Needs grant_files.

in_place_span fn

in_place_span(op, suffix)

op: ptr, suffix: string

-I suffix: as in_place, but line numbers, $ and the hold space span the files, as if they were one input.

delay_wfiles fn

delay_wfiles(op)

op: ptr

-a: create (truncate) w files when first written, not when a run starts.

line_wrap fn

line_wrap(op, n)

op: ptr, n: int

The line length the l command folds at (FreeBSD: COLUMNS, the terminal's width, or 60 when output is not a terminal; here 60 unless set).

grant_files fn

grant_files(op, exists_fn, read_fn, write_fn)

op: ptr, exists_fn: fn, read_fn: fn, write_fn: fn

Grant file access for r, w and the w flag of s, and for run_files and in-place editing. See SedFiles for the three closures.

add_expression fn

add_expression(op, text)

op: ptr, text: string

-e text: a script unit for compile_units (a newline is added, as sed does).

add_script fn

add_script(op, name, text)

op: ptr, name: string, text: string

-f name: a script file's contents as a unit for compile_units; name is what error messages call it.

compile fn

compile(script, opts) -> ptr!

script: string, opts: ptr

Compile one script, as `sed script` (or `sed -e script`) does. opts is from options(), or null for the defaults. Returns (prog, "") or (null, err), err in sed's words ("1: \"s/a\": unterminated substitute pattern"). Warnings (an unused label, ...) are in warnings(prog).

compile_units fn

compile_units(opts) -> ptr!

opts: ptr

Compile the units added to opts with add_expression and add_script, in order, as `sed -e ... -f ...` does.

free fn

free(pg as ptr) -> (_0, _1)

pg as ptr

warnings fn

warnings(prog) -> string

prog: ptr

What sed would have written to stderr while compiling: one warning a line.

run fn

run(prog, input) -> (string, string)

prog: ptr, input: string

Run prog over input, as `sed script < input`. Returns (output, err).

run_files fn

run_files(prog, names) -> (string, string)

prog: ptr, names: *StringSeq

Run prog over files, as `sed script file...`, reading them through the closures grant_files gave. Returns (output, err). With in_place the output goes back into the files instead. A file that cannot be read is skipped and named in err (sed's warning and exit status 1), and the rest are still run, as sed does.

stream_new fn

stream_new(prog) -> ptr!

prog: ptr

A stream over input that arrives in pieces (sed reading its stdin). Returns (stream, "") or (null, err): err when the program opens w files it has no grant for, or edits in place (which needs run_files).

stream_write fn

stream_write(stream, chunk) -> (string, string)

stream: ptr, chunk: string

Feed the next piece of input. Returns (output, err): the output the lines so far produced. A line is run once the byte after it has arrived (or stream_close says there is none), since $ depends on it.

stream_close fn

stream_close(stream) -> (string, string)

stream: ptr

The input is complete: run what is left. Returns (output, err).

stream_done fn

stream_done(stream) -> int

stream: ptr

1 when the program has finished (q, the end of the input, an error): more input would produce nothing.

stream_free fn

stream_free(st as ptr) -> (ptr, string)

st as ptr
