zlib

std.zlib - One-shot zlib and gzip deflate/inflate.

import std.zlib

backend_available extern

backend_available() -> int

Probe: returns 1 when the toolchain was built with zlib detected, 0 otherwise. Lets callers / tests distinguish "no backend" from "backend returned an error at runtime". C-side name is `zlib_backend_available` to avoid colliding with the Aether-side `zlib.available()` wrapper's mangled name.

available fn

available() -> int

Compress the bytes of `data` at the given level (0..9, or -1 for the library default). Returns (bytes, byte_count, "") on success, ("", 0, error) on failure. The returned string is length-aware: string.length(bytes) == byte_count. Alias for the capability probe. Use when skipping a test or choosing a fallback path.

deflate fn

inflate fn

inflate(data)

data: byte[]

Decompress the bytes of `data` (a zlib stream — RFC 1950). Returns (bytes, byte_count, "") on success, ("", 0, error) on corruption, truncation, or empty input. The output buffer grows geometrically — callers don't need to know the decompressed size in advance.

deflate_raw fn

deflate_raw(data, level)

data: byte[], level: int

Raw DEFLATE (RFC 1951) — no zlib/gzip wrapper — the COMPRESSING side. This is the framing a ZIP entry stores for method 8: the archive's central directory carries the sizes and CRC, so the stream has no header of its own. `level` is 0..9 (0 = store, 9 = best); -1 for the zlib default. std.zip's writer is the primary caller.

inflate_raw fn

inflate_raw(data)

data: byte[]

Raw DEFLATE (RFC 1951) — no zlib/gzip wrapper — the DECOMPRESSING side. This is the framing a ZIP entry stores for method 8 (deflate): the archive's central directory carries the sizes and CRC, so the stream itself has no header. std.zip is the primary caller.

stream_new fn

stream_new(format, level) -> (ptr, string)

format: int, level: int

Open a stream. Returns (handle, "") on success, (null, error) when zlib is absent, the format/level is out of range, or allocation fails. Every other stream call needs the handle, so an unavailable backend fails HERE rather than silently producing nothing later.

stream_write fn

stream_write(handle, data)

handle: ptr, data: byte[]

Feed bytes into the stream. Returns (bytes, byte_count, "") -- and the byte count is USUALLY 0, because deflate buffers internally for compression ratio. Emit whatever comes back, then call stream_flush when the event is complete.

stream_flush fn

stream_flush(handle) -> (string, int, string)

handle: ptr

Z_SYNC_FLUSH: emit everything buffered and end on a byte boundary the decoder can consume, WITHOUT closing the stream. This is the call that makes per-event streaming work.

stream_finish fn

stream_finish(handle) -> (string, int, string)

handle: ptr

Z_FINISH: emit the tail and any trailer. The handle takes no further writes; calling it twice is harmless and yields no bytes the second time. Still requires stream_free afterwards.

stream_free fn

stream_free(handle)

handle: ptr

Release the handle. Safe on null.

RAW const

RAW = 0

Framing for stream_new. RAW is bare DEFLATE (RFC 1951), ZLIB adds the RFC 1950 wrapper, GZIP the RFC 1952 one -- the last is what `Content-Encoding: gzip` means.
