clean extern

clean(path) -> string

Lexical normalize: collapses `//`, resolves `.` and `..`, drops trailing slashes — purely on the string, never touching the filesystem. Empty input → ".". POSIX-separator aware (`/`); on Windows, normalise `\` to `/` first if needed (see the module note / #1369).

rel extern

rel(base, target) -> string

base: string, target: string

Relative path from `base` to `target`, lexically (no FS access).

is_within_base extern

is_within_base(base, target) -> int

base: string, target: string

1 if `target` is lexically within `base` (no `..` escape), else 0.

separator extern

separator() -> string

The platform path separator: "/" on POSIX, "\\" on Windows. Use this instead of hardcoding "/" when a separator is genuinely needed. (#1369)

join_clean fn

join_clean(a, b) -> string

a: string, b: string

Lexically-cleaned join: append `b` to `a`, then collapse `.` and `..`. Use this rather than `join` wherever `b` is caller-supplied (an object key, an archive entry name), so a traversal is resolved before the path reaches the filesystem. Pair with `is_within_base` for the containment check. Same function std.fs exports; surfaced here because std.path is where path work is looked for (#1369).
