The field a notification carries when it does not name one: notify(obj), or a store whose field the compiler could not resolve.

observe fn

observe(obj, on_change) -> long

obj: ptr, on_change: fn

Register `on_change` to run after every field store on `obj`. Returns a token for unobserve, or 0 when `obj` is null.

fields fn

fields(obj, on_change) -> long

obj: ptr, on_change: fn

As observe, for an observer that also takes the changed field's index: `|obj: ptr, field: int|`. `field` is the stored field's position in the struct's declaration order, or ANY_FIELD for a notify(obj) that named none.

unobserve fn

unobserve(obj, token) -> bool

obj: ptr, token: long

Remove one registration. Returns true when the token was registered on `obj`. Safe from inside the observer being removed.

unobserve_all fn

unobserve_all(obj) -> int

obj: ptr

Remove every observer of `obj`; call before freeing it. Returns how many were removed.

observer_count fn

observer_count(obj) -> int

obj: ptr

How many observers `obj` has right now.

is_notifying fn

is_notifying(obj) -> bool

obj: ptr

True while a notification pass for `obj` is running.

notify fn

notify(obj)

obj: ptr

Run `obj`'s observers as a compiler-emitted store would, for a store the compiler did not see (one made through std.mem). The field is ANY_FIELD. A null `obj` is a no-op.

notify_field fn

notify_field(obj, field)

obj: ptr, field: int

As notify, naming the field that changed by its declaration index.
