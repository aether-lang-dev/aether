lanes

std.lanes - SIMD lanes for the f32x4 / f64x2 / i32x4 / f32x8 types (#2146) Import with: import std.lanes The lane types themselves are language types: `f32x4` is four C floats in one register, `f64x2` two doubles, `i32x4` four 32-bit integers and the mask a lane comparison yields.

sqrt4 extern

sqrt4(v) -> f32x4

v: f32x4

Lane-wise square root and absolute value. Both are EXACT — an IEEE square root is correctly rounded and clearing the sign bit is not an approximation — so these give the same lanes as calling the scalar form four times, in one instruction instead of four extracts, four calls and a rebuild. A negative lane yields NaN, as `sqrt` does. (The transcendentals are a different matter: `sin`/`exp` per lane are approximations with a choice to make, so they are not here.)

Two i32x4 -> one i16x8, signed-saturated: `a` fills lanes 0-3, `b` lanes 4-7. A lane outside [-32768, 32767] clamps to the nearest end.

pack_i16_u8 extern

pack_i16_u8(a, b, out)

Two i16x8 -> sixteen u8 written to `out`, unsigned-saturated: `a` fills bytes 0-7, `b` bytes 8-15. A lane below 0 clamps to 0, above 255 to 255. `out` must have room for 16 bytes.

bits4 extern

bits4(v) -> i32x4

v: f32x4

The same bits read as integer lanes, and back: a reinterpretation, not a conversion (`bits4(splat4(1.0))` is 0x3f800000 in every lane). With `mask_and` / `mask_or` (`mask8_and` / `mask8_or`), which are bitwise on any integer lanes, this edits a float's bits in place, as an index embedded in the low mantissa bits of a value is: tagged = from_bits8(mask8_or(mask8_and(bits8(v), i32splat8(0 - 128)), index))

reduce_min4 extern

reduce_min4(v) -> f32

v: f32x4

The smallest / largest lane. The lanes are compared in one fixed order with min4's rule (`a < b ? a : b`): for eight, lane i against lane i + 4 first, then as for four, lanes 0 and 2, 1 and 3, then the two winners. A tie or a NaN therefore gives the same answer on every instruction set and in either form of f32x8.
