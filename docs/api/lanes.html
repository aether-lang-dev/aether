lanes

std.lanes - SIMD lanes for the f32x4 / f64x2 / i32x4 / f32x8 types (#2146) Import with: import std.lanes The lane types themselves are language types: `f32x4` is four C floats in one register, `f64x2` two doubles, `i32x4` four 32-bit integers and the mask a lane comparison yields.

i16load_slice fn

i16load_slice(buf, index) -> i16x8

buf: uint16[], index: long

16-bit lanes store into `uint16[]` (the array-element width that matches i16x8's storage), not a signed `int16` — the language has no first-class signed 16-bit element type for arrays, and `i16lane` already sign-extends on the way out, same as the raw `ptr` form.
