reflect

std.reflect — read the field tables `@derive(schema)` emits (#2298) `@derive(schema)` on a struct makes the compiler emit, as static constant data, a table of the struct's fields: each one's name, type, offset and size, and the `@attr(...)` attributes written after its type.

field_heap_offset fn

field_heap_offset(s, field) -> int

s: ptr, field: int

For a KIND_STRING field, the offset of the int that records whether the struct owns the string (1: a heap string it frees when the field is reassigned or the struct is destroyed). A generic writer that stores a heap string sets it to 1, and frees the old string first when it was 1. -1 for every other kind.

The table of the struct a field holds (KIND_STRUCT), points at (KIND_PTR to `*T`), or holds an array of (KIND_ARRAY / KIND_SLICE of structs), when that struct is an Aether struct; null otherwise.
