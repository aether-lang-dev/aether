udp

bind fn

bind(host, port) -> (ptr, string)

host: string, port: int

Bind a datagram socket on host:port. "0.0.0.0" (or "") takes every IPv4 interface, "::" IPv6 (dual-stack where the OS allows), "127.0.0.1" or "::1" loopback only. Port 0 asks the OS for an ephemeral port; read it back with `local_port`. The socket is non-blocking. Returns (socket, "") or (null, error). Caller must udp.close it.

local_port fn

local_port(sock) -> int

sock: ptr

The port a socket is bound to (the one the OS chose for a bind on 0), or -1 for a null handle.

fd fn

fd(sock) -> int

sock: ptr

The OS-level descriptor inside a socket, or -1 for a null handle. For a poll across several sockets, or capsicum narrowing. Owned by the handle: do not close it directly, it is released by udp.close.

poll fn

poll(sock, timeout_ms) -> (_0, string)

sock: ptr, timeout_ms: int

Wait until a datagram is waiting, up to timeout_ms (-1 blocks, 0 polls, >0 waits that many ms). Returns (true, "") when a recv_from will return a packet, (false, "") on timeout, (false, error) on a null handle.

set_buffer_sizes fn

set_buffer_sizes(sock, send_bytes, recv_bytes) -> string

sock: ptr, send_bytes: int, recv_bytes: int

SO_SNDBUF / SO_RCVBUF in bytes; 0 leaves that side as it is. A server fanning snapshots out to many peers wants a larger send buffer than the default. Returns "" or an error.

set_broadcast fn

set_broadcast(sock, on) -> string

sock: ptr, on: bool

Allow sends to a broadcast address (255.255.255.255 or the subnet's), for LAN discovery on an IPv4 socket. Returns "" or an error.

resolve fn

resolve(host, port) -> (ptr, string)

host: string, port: int

Resolve host:port once to an address value for `send_to_addr`. Returns (addr, "") or (null, error). Caller must addr_free it.

addr_clone fn

addr_clone(addr) -> ptr

addr: ptr

A copy of an address, to keep past the receive that produced it.

addr_host fn

addr_host(addr) -> string

addr: ptr

The numeric host of an address ("10.0.0.7", "fe80::1"), or "" for a null or unset one.

addr_port fn

addr_port(addr) -> int

addr: ptr

The port of an address, or -1 for a null or unset one.

addr_string fn

addr_string(addr) -> string

addr: ptr

"host:port" ("[host]:port" for IPv6), the natural map key for a peer table. "" for a null or unset address.

addr_equal fn

addr_equal(a, b) -> bool

a: ptr, b: ptr

True when both addresses name the same family, host and port. Two null or unset addresses are not equal.

addr_hash fn

addr_hash(addr) -> int

addr: ptr

A non-negative hash of an address, stable for equal addresses within a process. 0 for a null or unset one.

send_to fn

send_to(sock, host, port, data)

sock: ptr, host: string, port: int, data: byte[]

Send one datagram holding the bytes of `data` — its length is the datagram size (#2301) — to host:port, resolving the name each call. For a string pass `string.bytes(s)`; for a `std.bytes` buffer, `bytes.view(buf)`. An empty slice sends a zero-length datagram, which UDP permits. Returns (bytes_sent, "") or (0, error). A dropped packet (full send buffer) is an error: a datagram protocol expects loss and resends on its own schedule.

send_to_addr fn

send_to_addr(sock, addr, data)

sock: ptr, addr: ptr, data: byte[]

Send to an already-resolved address: the per-peer form for a server answering many peers a tick. Returns (bytes_sent, "") or (0, error).

recv_from fn

recv_from(sock, buf)

sock: ptr, buf: byte[]

Receive one datagram into `buf`, at most `buf.len` bytes (#2301); a longer packet is truncated, and the datagram is `buf[0..n]`. For a `std.bytes` buffer pass `bytes.capacity_view(buf)`. Never blocks. Returns (n, sender, "") on a packet, (0, null, "would block") when nothing is waiting (the socket is fine: come back next tick), (0, null, error) on failure, including an empty `buf`; an unbounded one panics. The sender must be addr_free'd; use recv_from_into to reuse one across packets.

recv_from_into fn

recv_from_into(sock, buf, addr)

sock: ptr, buf: byte[], addr: ptr

recv_from with a caller-owned address (`addr_new`) filled in place, so the drain loop allocates nothing. Reads at most `buf.len` bytes; the datagram is `buf[0..n]`. Returns (n, "") on a packet, (0, "would block") when nothing is waiting, (0, error) on failure.

send_slice_to fn

send_slice_to(sock, host, port, s) -> (int, string)

sock: ptr, host: string, port: int, s: byte[]

send_to over a slice: one datagram of exactly `s.len` bytes to host:port, resolving the name each call. An empty slice sends an empty datagram. Returns (bytes_sent, "") or (0, error).

send_slice_to_addr fn

send_slice_to_addr(sock, addr, s) -> (int, string)

sock: ptr, addr: ptr, s: byte[]

send_to_addr over a slice: one datagram of `s.len` bytes to a resolved address. Returns (bytes_sent, "") or (0, error).

recv_slice_from fn

recv_slice_from(sock, buf) -> (int, ptr, string)

sock: ptr, buf: byte[]

recv_from into a slice: the datagram lands in `buf[0..n]` (truncated to `buf.len`, see above). Never blocks. Returns (n, sender, "") on a packet, (0, null, "would block") when nothing is waiting, (0, null, error) on failure. An empty slice returns (0, null, "receive buffer is empty") without consuming a datagram. The sender must be addr_free'd.

recv_slice_from_into fn

recv_slice_from_into(sock, buf, addr) -> (int, string)

sock: ptr, buf: byte[], addr: ptr

recv_from_into into a slice, with a caller-owned address (`addr_new`) filled in place: the allocation-free drain loop. Returns (n, "") with the datagram in `buf[0..n]`, (0, "would block") when nothing is waiting, (0, error) on failure, and (0, "receive buffer is empty") for an empty slice without consuming a datagram.
