sharedmap

std.sharedmap — the shared map, from Aether: a token-guarded map of strings a host fills with a hosted language's inputs and reads its outputs back from (a guest bridge's aether_map_get / aether_map_put, a sandboxed child through a shared memory block).

import std.sharedmap

new fn

new() -> ptr

A new, empty map, the caller's to free; null without memory.

token fn

token(m) -> long

m: ptr

The token a hosted language reaches the map through (for a bridge's *_with_map runner). It dies when the map is freed.

put fn

put(m, key, value) -> int

m: ptr, key: string, value: string

m[key] = value, both by their length: 0, or -1 when refused (the map full with a new key, no memory), the map unchanged.

get fn

get(m, key) -> (string, int)

m: ptr, key: string

m[key]: (the value, 1), or ("", 0) when the key is absent.

has fn

has(m, key) -> int

m: ptr, key: string

1 when key is in the map, else 0.

count fn

count(m) -> int

m: ptr

Keys in the map; key_at and value_at read entry i (0 .. count - 1), in the order keys were first put; "" past the end.

key_at fn

key_at(m, i) -> string

m: ptr, i: int

value_at fn

value_at(m, i) -> string

m: ptr, i: int

freeze fn

freeze(m)

m: ptr

Make every key put so far an input: a guest reads it and cannot overwrite it (guest_put refuses), and a child's shared memory block cannot either.

free fn

free(m)

m: ptr

Frees the map and everything in it; its token is dead from now on.

guest_put fn

guest_put(token, key, value) -> int

token: long, key: string, value: string

A put with a guest's rules, through the token, as a host serving a guest in another process applies one: 0, or -1 (a dead token, a frozen input, the map full).

MAX_ENTRIES const

MAX_ENTRIES = 256

The most keys one map holds.
