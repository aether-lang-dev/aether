available fn

available() -> int

1 when the toolchain was built with libbrotli detected. Use it to skip a test or pick a fallback encoding rather than threading an error everywhere.

decoder_available fn

decoder_available() -> int

1 when decoding works here: brotli is built in AND the system libbrotlidec carries the CVE-2026-111497 fix (an out-of-bounds write on malformed input, libbrotli 1.0.3 to 1.2.0). Without the fix every decode refuses with an error rather than run a decoder that untrusted input can exploit; encoding is unaffected. The check asks the library itself, so a distro backport that keeps the old version number passes.

compress fn

compress(data, quality)

data: byte[], quality: int

One-shot: compress a body already in memory. Returns (bytes, count, "") on success, ("", 0, error) otherwise. Quality out of range is clamped.

decompress fn

decompress(data)

data: byte[]

One-shot: decompress with the default 1 GiB ceiling. Returns (bytes, count, "") on success, ("", 0, error) otherwise. For input you did not produce, use decompress_max with a cap that fits the job.

decompress_max fn

decompress_max(data, max_bytes)

data: byte[], max_bytes: int

One-shot with a cap: decoding stops, and returns an "output limit exceeded" error, as soon as the output would pass `max_bytes` (0 = the 1 GiB ceiling). Truncated input, corrupt input and bytes after the end of the stream are errors too.

stream_new fn

stream_new(quality, window) -> (ptr, string)

quality: int, window: int

Open a stream. `window` is the lg2 window size (10..24); pass 0 for the library default. Returns (handle, "") or (null, error) — an unavailable backend fails HERE, not silently later, because every other stream call needs the handle.

stream_write fn

stream_write(handle, data)

handle: ptr, data: byte[]

Feed bytes. Returns (bytes, count, "") — the count is usually 0, because the encoder buffers internally for compression ratio. Emit whatever comes back, then stream_flush when the event is complete.

stream_flush fn

stream_flush(handle) -> (string, int, string)

handle: ptr

Emit everything buffered so far at a boundary the decoder can consume, WITHOUT ending the stream. This is what makes per-event streaming work.

stream_finish fn

stream_finish(handle) -> (string, int, string)

handle: ptr

Emit the tail. The handle takes no further writes; calling it twice is harmless and yields no bytes the second time. Still needs stream_free.

stream_free fn

stream_free(handle)

handle: ptr

Release the handle. Safe on null.

decompress_stream_new fn

decompress_stream_new(max_bytes) -> (ptr, string)

max_bytes: int

Open a decoding stream whose total output is capped at `max_bytes` (0 = the 1 GiB ceiling). Returns (handle, "") or (null, error).

decompress_stream_write fn

decompress_stream_write(handle, data)

handle: ptr, data: byte[]

Feed compressed bytes in any size of chunk. Returns (bytes, count, "") with whatever they decoded to. After an error the handle refuses further writes.

decompress_stream_finish fn

decompress_stream_finish(handle) -> (string, int, string)

handle: ptr

Confirm the stream ended. Returns ("", 0, "") when it did, and a "truncated stream" error when the input stopped short of the end, so a cut connection is not mistaken for a shorter body. Still needs decompress_stream_free.

decompress_stream_free fn

decompress_stream_free(handle)

handle: ptr

Release a decoding stream. Safe on null.

MIN_QUALITY const

MIN_QUALITY = 0

Quality bounds, matching libbrotli's own range. 11 is the library default and is SLOW; 4..6 is the usual choice for a live HTTP response.
