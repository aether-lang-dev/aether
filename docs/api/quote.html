helper_count fn

helper_count(t) -> int

t: Tree

---- @quotable functions (version 2) ---- Every @quotable function a quote's body reaches, through its own calls or a helper's, callees before their callers: the order a back end that wants each declared before its use (GLSL) writes them in. Each is a Tree with a name, a return type, its parameters and its body, and no captures; a HELPER_CALL names one. They are freed with the quote's tree.

walk fn

walk(n, f)

n: Node, f: fn

Call `f` with `n` and then with every node under it, in pre-order (a node before its children, children first to last): quote.walk(quote.body(t)) callback | m: quote.Node | { if quote.kind(m) == quote.CALL { println(quote.name(m)) } }

to_source fn

to_source(t) -> string

t: Tree

The quote printed back as Aether: `| a: T, b: U | { ... }`, or the block alone when it has no parameters. A `->` body comes back as the block it stands for (`{ return expr }`).

dump fn

dump(t) -> string

t: Tree

The tree as an s-expression with every node's kind, name, operator, literal and type: `(BINARY * :float (LOCAL a :float) (LIT 2.0 :float))`. For tests and for reading what a back end will see.

free(t)
