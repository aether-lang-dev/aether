host

std.host — primitives for Aether scripts embedded in a host application.

import std.host

notify extern

notify(event, id) -> int

event: string, id: long

Emit an event to the host process. Returns 1 if a handler was found and invoked, 0 if no listener is registered for this event name. `long` is Aether's 64-bit integer (TOKEN_INT64); the C-side ABI is int64_t per the public host header (runtime/aether_host.h).

describe(_ctx, name)

_ctx: ptr, name: string

Begin a namespace declaration. The trailing block contains input(), event(), and bindings() calls.

manifest_get extern

manifest_get() -> ptr

Read the captured manifest. Returns a ptr to an opaque AetherManifest struct (see runtime/aether_host.h). Used by tests and the dlopen pipeline; user code rarely calls this.

manifest_clear extern

manifest_clear()

Reset the captured manifest. Intended for tests and for the pipeline to start each compilation from a clean slate.

account_new fn

account_new(memory_bytes, deadline_ms, counts, parent) -> ptr

memory_bytes: long, deadline_ms: long, counts: int, parent: ptr

A new account: at most `memory_bytes` live (0: no limit of its own), a deadline of `deadline_ms` (0: none) counted as host.DEADLINE_ELAPSED or host.DEADLINE_ACTIVE, and `parent` (null, or an account it narrows: what it holds counts against the parent too). null when out of memory, or when `parent` is no live account (freed, or another runtime copy's).

account_free fn

account_free(account)

account: ptr

Frees an account. The blocks charged to it are detached (its parent chain credited for them), and its children go under its own parent. Freed while in use, it is in use no more: account_in_use() is null after, here and, from its next allocation or call, on any other thread.

account_use fn

account_use(account) -> int

account: ptr

Puts `account` (null: none) in use on this thread: 0, or -1 when it is in use on another thread.

account_in_use fn

account_in_use() -> ptr

The account in use on this thread, or null.

account_used fn

account_used(account) -> long

account: ptr

The live bytes charged to `account` (and its children).
