strarr

std.strarr - a growable array of string pointers whose backing IS a `string[]`, so it feeds std.sort directly.

import std.strarr

new fn

new() -> ptr

A fresh empty growable string array.

new_hint fn

new_hint(hint) -> ptr

hint: int

Empty array pre-sized for `hint` elements (avoids early regrowth when you know roughly how many you'll push).

push fn

push(arr, s) -> string

arr: ptr, s: string

Append `s` BORROWED — the string must outlive the array (and any sorted read of it). Returns "" on success, an error string on OOM.

push_copy fn

push_copy(arr, s) -> string

arr: ptr, s: string

Append an OWNED copy of `s` — the array takes its own reference and frees it in `free`, so you can push a string you just built (a per-iteration concat / basename) without keeping it alive yourself. Returns "" on success, an error string on OOM.

get fn

get(arr, i) -> string

arr: ptr, i: int

Element at `i` (null if out of range).

set fn

set(arr, i, s)

arr: ptr, i: int, s: string

Overwrite element at `i`.

size extern

size(arr) -> int

arr: ptr

Number of elements. -1 if null.

array fn

array(arr) -> string[]

arr: ptr

The elements as a `string[]` bounded by the size (#2301), for std.sort (`sort.strings_by(strarr.array(sa), cmp)` sorts them in place) or any `string[]` parameter. `v[i]` outside it is the slice bounds panic. Valid until the next push (which may reallocate) or free. A null handle is the empty slice.

free extern

free(arr)

arr: ptr

Free the spine only; borrowed elements are the caller's.

new_raw extern

new_raw(hint) -> ptr

hint: int

Allocate an empty array with room for `hint` elements (0 = first push allocates). Returns null on OOM.

push_raw extern

push_raw(arr, s) -> int

arr: ptr, s: string

Append `s` (borrowed). Grows 2× when full. 1 on success, 0 on OOM.

push_copy_raw extern

push_copy_raw(arr, s) -> int

arr: ptr, s: string

Append an OWNED reference to `s` (retains a managed string / copies a literal), freed at strarr.free. 1 on success, 0 on OOM.

get_raw extern

get_raw(arr, i) -> string

arr: ptr, i: int

Read at `i`. null if out of range.

set_raw extern

set_raw(arr, i, s)

arr: ptr, i: int, s: string

Overwrite at `i` (borrowed). No-op if out of range.

data extern

data(arr) -> string[]

arr: ptr

The raw `string[]` backing — a bare array of `strarr_size` elements, so `sort.strings_by` sorts it in place. Valid until the next push (may realloc) or free.
