sandbox

std.sandbox — build a grant list and run code under it.

import std.sandbox

new fn

new(name) -> ptr

name: string

A new, empty grant list named `name` (the name is for the reader and for denial logs; it does not change what is allowed). Give it grants in the trailing block; with none it denies everything. Release with free().

enforce fn

enforce(perms, code)

perms: ptr, code: fn

Run `code` with `perms` in force: every sandbox-checked operation inside it, and in anything it calls, must match one of the grants. The grants stop applying when `code` returns. Trusted names: `sandbox.enforce(perms, audit_log, db) callback { ... }`. A call written in the block to a named function (`audit_log(...)`), or into a named module (`db.query(...)`), runs with the authority of the code that wrote the enforce instead of the block's grants. The compiler handles the extra names (compiler/analysis/sandbox_trust.c): it checks them, routes those calls through wrappers, and leaves this two-argument function to do the rest. Trust is lexical and narrow on purpose: - a trusted call's arguments are still evaluated inside the sandbox; - a function called from somewhere else, even one that calls a trusted name, stays sandboxed; - the names cannot be used as values in the block; - only Aether functions can be trusted, not C externs; - an enforce written by contained code records the sandboxed authority it runs under, so trusting a name there gains nothing.

free fn

free(perms)

perms: ptr

Release a grant list made by new(), and the grant strings it owns.

grant_all fn

grant_all(_ctx)

_ctx: ptr

Everything: the equivalent of no sandbox.

grant_fs_read fn

grant_fs_read(_ctx, path)

_ctx: ptr, path: string

Opening files for reading whose resolved path matches `path`.

grant_fs_write fn

grant_fs_write(_ctx, path)

_ctx: ptr, path: string

Opening, creating or writing files whose resolved path matches `path`.

grant_fs fn

grant_fs(_ctx, path)

_ctx: ptr, path: string

Reading and writing under `path`, plus directory operations on it (such as os.chdir, which std checks under its own "fs" category).

grant_exec fn

grant_exec(_ctx, cmd)

_ctx: ptr, cmd: string

Running commands whose command line matches `cmd` ("echo *").

grant_env fn

grant_env(_ctx, name)

_ctx: ptr, name: string

Reading the environment variables whose names match `name`.

grant_tcp fn

grant_tcp(_ctx, host)

_ctx: ptr, host: string

Outbound TCP to hosts matching `host` ("db.internal", "*.corp"). The LD_PRELOAD layer sees only the resolved address, so grant the IP too for code that connects outside std.net. Ports are not checked.

grant_tcp_listen fn

grant_tcp_listen(_ctx)

_ctx: ptr

Listening for and accepting inbound TCP connections, on any port.

grant_udp fn

grant_udp(_ctx, host)

_ctx: ptr, host: string

UDP to and from hosts matching `host`.

grant_native fn

grant_native(_ctx, path)

_ctx: ptr, path: string

Loading native code (dlopen) from paths matching `path`.
