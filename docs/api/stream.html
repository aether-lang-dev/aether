stream

std.stream: credit-windowed streams between actors (#426).

import std.stream

StreamChunk message

message StreamChunk {
    s: ptr, data: string, last: int
}

One chunk of stream `s`; `last` 1 (and no data) ends it.

StreamCredit message

message StreamCredit {
    s: ptr, n: int
}

`n` more chunks of stream `s` may be sent; `n` 0 is the consumer's end of it, after its last credit.

connect fn

connect(producer, consumer, window) -> ptr

producer: actor_ref, consumer: actor_ref, window: int

A stream from `producer` to `consumer` with at most `window` chunks in flight, or null when `window` is less than 1. Give it to both actors; the consumer's end frees it (see stream.credit).

offer fn

offer(s, data) -> int

s: ptr, data: string

The producer's: sends `data` as the next chunk. 1 when it was sent; 0 when the window is full (send it again after the next StreamCredit); -1 after finish.

write fn

write(s, data, at, chunk) -> int

s: ptr, data: string, at: int, chunk: int

The producer's: sends `data` from byte `at` on, in chunks of at most `chunk` bytes, while the window allows. Returns the byte it got to: the length of `data` when all of it went, less when the window filled (call again from there after the next StreamCredit); -1 after finish, or when `chunk` is less than 1.

finish fn

finish(s)

s: ptr

The producer's: the stream is done. The consumer gets the last chunk after every chunk sent before it. It costs no credit; the producer still takes StreamCredits until stream.credit says the stream has ended.

credit fn

credit(s, n) -> int

s: ptr, n: int

The producer's, for each StreamCredit it receives: 1 when `n` chunks more may be sent; 0 when this is the consumer's end of the stream, which is freed now (the producer drops it).

consumed fn

consumed(s, last)

s: ptr, last: int

The consumer's, in its StreamChunk arm once it has handled the chunk: returns its credit to the producer or, for the last chunk (`last` 1, the chunk's own field), ends the stream for the consumer, which drops it.

available fn

available(s) -> int

s: ptr

The producer's: chunks it may send now.

in_flight fn

in_flight(s) -> int

s: ptr

The producer's: chunks sent whose credit has not come back yet.

peak fn

peak(s) -> int

s: ptr

The producer's: the most chunks that were in flight at once (never more than the window).
