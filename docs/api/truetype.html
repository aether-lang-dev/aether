struct GlyphPoints

A glyph's points: font units, each on or off the curve, and the index of each contour's last point. A compound glyph's components arrive placed.

struct GlyphOutline

A glyph's outline as line segments: font units times a scale, y up, the pen's origin at 0.

full_name fn

full_name(f) -> string

f: *Typeface

The face's full name ("DejaVu Sans Bold"), `name` record 4. The English Macintosh record (plain bytes) is preferred, then the English Windows record (UTF-16BE, its Latin-1 characters kept), then any record 4: fonts carry the same name in several languages, and a non-English record would give another script's name. "" when the font names itself nowhere.

is_monospace fn

is_serif fn

is_serif(f) -> bool

f: *Typeface

A serif face, as OS/2's PANOSE declares it: family kind 2 (Latin text) with a serif style of 2 to 10 (11 to 15 are the sans styles). False when the font carries no OS/2 table or classifies itself otherwise.
