parse fn

parse(cbor_data) -> ptr!

cbor_data: string

Parse a CBOR binary string. Returns (value_ptr, "") on success, (null, error) on failure. Caller owns the returned value and must free with cbor.free.

encode fn

encode(value) -> string!

value: ptr

Serialize a CBOR value tree to a binary string. Returns (encoded_bytes, "") on success, ("", error) on failure.

stringify fn

stringify(value) -> string!

value: ptr

Alias of encode for JSON symmetry.
