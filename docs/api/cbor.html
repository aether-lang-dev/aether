parse_with fn

parse_with(cbor_data, opts) -> ptr!

cbor_data: string, opts: CborDecodeOptions

Parse one CBOR data item that is the whole of `cbor_data`, under `opts`. Returns (value_ptr, "") on success, (null, error) on failure. Caller owns the returned value and must free with cbor.free. Bytes left after the item are an error (#2470): `0102` used to parse as 1.

get_int64 fn

get_int64(value) -> long!

value: ptr

The integer as a signed long, or an error when `value` is not an integer or is one outside -2^63..2^63-1 (#2510).

get_uint fn

get_uint(value) -> long!

value: ptr

A non-negative integer (major type 0), 0..2^64-1, as the bit pattern of a long: 2^63 and up read negative as a long, and std.bits' udiv64, urem64 and ucmp64 treat them as the unsigned values they are. An error for a negative integer or anything else.

get_nint fn

get_nint(value) -> long!

value: ptr

A negative integer (major type 1) as its CBOR argument n, the value being -1 - n: n is 0..2^64-1, the bit pattern of a long as for get_uint, so the whole range down to -2^64 is reachable. An error for anything else.

from_uint fn

from_uint(bits) -> ptr

bits: long

The non-negative integer whose unsigned 64 bits are `bits` (0..2^64-1), the inverse of get_uint.

from_nint fn

from_nint(bits) -> ptr

bits: long

The negative integer -1 - n for the unsigned 64-bit argument n in `bits` (-2^64..-1), the inverse of get_nint.
