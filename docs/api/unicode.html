casefold fn

casefold(s) -> string

s: string

Unicode case folding for caseless comparison (NOT lowercasing): maps e.g. German 'ß' to "ss". Owned string.

grapheme_len fn

grapheme_len(s) -> int

s: string

Number of grapheme clusters (user-perceived characters). A combining sequence (e + U+0301) or an emoji ZWJ sequence counts as one.

grapheme_substring fn

grapheme_substring(s, start, count) -> string

s: string, start: int, count: int

The substring spanning grapheme clusters [start, start+count), never splitting a multi-byte character or a combining sequence. count < 0 means to the end. Owned string.

equals_ignore_case fn

equals_ignore_case(a, b) -> int

a: string, b: string

Caseless equality: fold both sides, compare. Returns 1 if equal.

equals_fold_accents fn

equals_fold_accents(a, b) -> int

a: string, b: string

Accent- AND case-insensitive equality: "Café" matches "cafe". Fold accents, then casefold, on both sides, then compare. Returns 1 if equal.
