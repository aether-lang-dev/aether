parent_channel fn

parent_channel() -> int

Returns the parent-channel fd if the parent spawned this process via os.run_pipe or os.run_socket (i.e. AETHER_IPC_FD is set in env and the named fd is open); -1 otherwise.

parent_channel_kind fn

parent_channel_kind() -> string

Returns the channel kind: "pipe" for a pipe channel, "socket" for a socket channel, or "" when no channel exists.

write fn

write(fd, bytes) -> string

fd: int, bytes: string

Write `bytes` to `fd`. Returns "" on success, non-empty error string on failure. Loops on short writes and handles SIGPIPE / EINTR.

write_close fn

write_close(fd, bytes) -> string

fd: int, bytes: string

Write `bytes` then close the channel.

read fn

read(ch, max) -> (string, string)

ch: int, max: int

Binary-safe read of up to `max` bytes from `fd`. Returns (payload, err). On EOF (end-of-stream), returns ("", ""). On error, returns ("", err).

send_fd fn

send_fd(ch, fd, payload) -> string

ch: int, fd: int, payload: string

Send one open file descriptor `fd` across socket channel `ch`, accompanied by `payload` (must be at least 1 byte). Returns "" on success, error message on failure.

recv_fd fn

recv_fd(ch, max) -> (int, string, string)

ch: int, max: int

Receive one open file descriptor and payload up to `max` bytes from socket channel `ch`. Returns (received_fd, payload, err).
