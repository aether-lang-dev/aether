zip

std.zip — a ZIP archive READER and WRITER over an in-memory byte buffer, plus a safe-by-default extract-to-disk layer (#2010 and follow-ups).

import std.zip

METHOD_STORED const

METHOD_STORED = 0

METHOD_DEFLATE const

METHOD_DEFLATE = 8

open fn

open(data) -> (ptr, string)

data: byte[]

Open a ZIP archive held entirely in `data` (#2301: a byte[] whose length travels with it — pass a string as `string.bytes(s)`, a `std.bytes` buffer as `bytes.view(buf)`). Returns (archive_ptr, "") or (null, err). The archive owns a copy of the bytes, so `data` need not outlive this call; free the archive with close().

entry_read fn

entry_read(arp, i) -> (string, int, string)

arp: ptr, i: int

Read and decompress entry `i`, verifying its CRC-32. Returns (bytes_as_string, length, "") or ("", 0, err). The local file header is consulted only to skip its variable name+extra fields to reach the data; the sizes/CRC come from the central directory.

writer_new fn

Start a fresh in-memory archive. Free it with writer_free.

writer_add fn

writer_add(wp, name, data, method, level) -> string

wp: ptr, name: string, data: byte[], method: int, level: int

Add a file entry holding the bytes of `data` (#2301: pass a string as `string.bytes(s)`). `name` is the archive path (forward slashes). `method` is zip.METHOD_STORED or zip.METHOD_DEFLATE; `level` is 0..9 (or -1) and is ignored for stored. Returns "" on success, else an error. The bytes are copied into the archive, so `data` need not outlive the call.

writer_add_dir fn

writer_add_dir(wp, name) -> string

wp: ptr, name: string

Add a directory entry (a name ending in "/", zero-length, stored). A "/" is appended if the caller left it off.

writer_finish fn

writer_finish(wp) -> (string, int, string)

wp: ptr

Finish: append the Central Directory and EOCD, and return the archive as (bytes, length, ""). ZIP64 records are emitted when any field overflows 32 bits. The writer's buffer still owns the bytes; free with writer_free after the returned string has been used (it is an independent copy). Inferred return type (`-> {`), not an explicit `(string, int, string)`: the archive bytes come from bytes.to_string, whose `@heap` classification only propagates to the caller's destructure site through an inferred tuple. An explicit tuple type cannot carry the per-position `@heap` flag, so the returned string would leak when passed on (e.g. through create).

writer_free fn

writer_free(wp)

wp: ptr

Release a writer and every entry it holds. Safe on a null pointer.

create(name, data, method, level) -> (_0, _1, _2)

One-shot convenience: build a single-entry archive. For multiple entries use writer_new / writer_add / writer_finish.

add_dir_tree fn

add_dir_tree(wp, fs_root, arc_prefix, method, level) -> string

wp: ptr, fs_root: string, arc_prefix: string, method: int, level: int

Add a filesystem tree to the writer. `arc_prefix` is prepended to every entry name (use "" for none; a trailing "/" is added if missing and prefix is non-empty). `method`/`level` apply to every file. Returns "" or the first error encountered.

struct ExtractOptions

default_extract_options fn

default_extract_options() -> ExtractOptions

Safe defaults: 10k entries, 1 GiB per entry, 10 GiB total, no overwrite.

extract fn

extract(data, dest_dir, options) -> string

data: byte[], dest_dir: string, options: ExtractOptions

Extract the archive held in `data` (a byte[], #2301) under `dest_dir`, applying `options`. Returns "" on success, else a descriptive error; on error, files written so far are left in place (as std.tar does). The destination is created if absent.

extract_file fn

extract_file(zip_path, dest_dir, options) -> string

zip_path: string, dest_dir: string, options: ExtractOptions

Convenience: read a .zip off disk and extract it. The buffer-taking extract is the primary entry point; this wraps fs.read_binary for the common case.
