new fn

new(capacity_hint) -> ptr

capacity_hint: int

A map with room for about `capacity_hint` entries before it first grows (0 for the default). Null on allocation failure.

put fn

put(m, key, value) -> int

Set `key` to `value`. 1 when the key was new, 0 when it replaced a value, -1 on allocation failure or a null map.

add fn

add(m, key, delta) -> long

m: ptr, key: long, delta: long

Add `delta` to the value at `key` (an absent key starts at 0) and return the new value, in one probe: the counting loop's call. Allocation failure while inserting a new key panics, as `make` does.

next fn

next(m, slot) -> int

m: ptr, slot: int

Iteration, in no particular order: the first occupied slot at or after `slot`, or -1 when there are no more. Start at 0 and continue from the returned slot + 1: s = intmap.next(m, 0) while s >= 0 { println("${intmap.key_at(m, s)} = ${intmap.value_at(m, s)}") s = intmap.next(m, s + 1) } A put or add of a new key, or clear, may rebuild the table: finish the walk (or collect the keys) before changing the map.
