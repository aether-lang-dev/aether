audio

std.audio — audio playback (v1: playback tier).

import std.audio

open fn

open() -> bool

Initialise the audio engine. Call once before loading/playing. Returns true on success. v1 always succeeds (null backend).

open_headless fn

open_headless(sample_rate, channels) -> bool

sample_rate: int, channels: int

Open a HEADLESS engine instead: no device, no mixer thread. Nothing advances — no position, no played frame, no fade — until `render` pulls frames through the mixer, so every number a test reads back follows from the calls it made rather than from wall-clock time. Use it to hold a mix to numbers the way a renderer is held to pixels. Returns false (with `last_error`) if an engine is already open. `is_null_backend` is also true for a headless engine.

close fn

close()

Shut the engine down. Unload sounds and free groups first.

is_null_backend fn

is_null_backend() -> bool

True when the active backend is the NULL (silent) backend — the v1 default. Lets a caller / test assert deterministic, device-free behaviour.

is_headless fn

is_headless() -> bool

True when the engine was opened with `open_headless`.

load_wav fn

load_wav(data, length) -> ptr!

data: string, length: int

Decode `length` bytes of `data` (a WAV byte string — e.g. from fs.read_binary) into a playable source. Returns the source on success, or a non-empty error on malformed / unsupported input. The source is owned by the caller: release it with `unload`.

load_pcm fn

load_pcm(data, length, sample_rate, channels, format) -> ptr!

data: string, length: int, sample_rate: int, channels: int, format: int

Play PCM samples the caller ALREADY decoded, rather than an encoded container (asks/pcm-please.md). `load_wav` is really a format-sniffing decoder — it accepts mp3 and flac too — but every entry point wants bytes miniaudio can demux itself. That leaves no way in for samples a *different* decoder produced, which is exactly the case when contrib.avcodec has demuxed an MP4 and holds the audio packets. The workaround was pre-extracting a sidecar WAV: roughly doubling on-disk cost, a manual step before playback, and nothing at all for a live source with no file to extract from. `data` is interleaved samples, `length` its byte count, `format` one of the FORMAT_* constants above. The bytes are copied, so the caller's buffer need not outlive the source. Everything downstream works exactly as for `load_wav` — play, pause, position_ms, duration_ms, seek_ms, volume — because they all read the underlying sound, not the decoder. position_ms in particular remains usable as an A/V-sync master clock. `length` must be a whole number of frames (bytes-per-sample x channels); a partial trailing frame is refused rather than played as noise.

last_error fn

last_error() -> string

The reason the most recent load failed (or "" after a success). BORROWED from the substrate — a static C string valid until the next load_wav.

FORMAT_U8 const

FORMAT_U8 = 1

PCM sample formats for `load_pcm`. These mirror miniaudio's ma_format_* numbering so a caller never has to hardcode it. FORMAT_S16 (interleaved 16-bit signed) is what most decoders emit and what ffmpeg's `s16le` means.

FORMAT_S16 const

FORMAT_S16 = 2

FORMAT_S24 const

FORMAT_S24 = 3

FORMAT_S32 const

FORMAT_S32 = 4

FORMAT_F32 const

FORMAT_F32 = 5

play fn

play(src) -> bool

src: ptr

Start or resume playback from the current position. Returns true on success (false only for a null source). A source that had reached its end rewinds to the start.

pause fn

pause(src) -> bool

src: ptr

Halt playback, keeping the current position for a later `play`.

stop fn

stop(src) -> bool

src: ptr

Halt playback and rewind to the start.

is_playing fn

is_playing(src) -> bool

src: ptr

True while the source is actively playing (false when paused, stopped, or finished).

volume fn

volume(src, v) -> bool

src: ptr, v: float

Set the source's volume in [0.0, 1.0] (clamped). Returns true on success.

get_volume fn

get_volume(src) -> float

src: ptr

The source's current volume in [0.0, 1.0].

pan fn

pan(src, p) -> bool

src: ptr, p: float

Set the stereo pan in [-1.0, 1.0] (clamped): -1 wholly left, 0 centre, 1 wholly right. Equal-power, the Web Audio StereoPannerNode law, so a source keeps its loudness as it moves: a mono source at 0 sits at cos(pi/4) in each ear and at -1 at full gain in the left alone; a stereo source passes through unchanged at 0 and folds its far channel into the near one as it moves. The engine computes `p` from the listener's frame each tick and calls this. Returns true on success.

get_pan fn

get_pan(src) -> float

src: ptr

The pan last applied, in [-1.0, 1.0].

pitch fn

pitch(src, ratio) -> bool

src: ptr, ratio: float

Set the playback-rate ratio: 2.0 plays an octave up in half the time, 0.5 an octave down in twice. Doppler, an engine note, variation between repeats of a clip. A ratio <= 0 is refused (false, see `last_error`).

get_pitch fn

get_pitch(src) -> float

src: ptr

The pitch ratio last applied (1.0 by default).

looping fn

looping(src, on) -> bool

src: ptr, on: bool

Loop back to the start on reaching the end: engines, rain, wind, ambience. A stream cannot loop (false). Returns true on success.

is_looping fn

is_looping(src) -> bool

src: ptr

True when the source loops.

fade_ms fn

fade_ms(src, from, to, ms) -> bool

src: ptr, from: float, to: float, ms: long

Fade the volume from `from` to `to` over `ms` milliseconds, starting now (at the next mixed frame). A `from` of -1.0 means "from wherever the volume is now" — the shape of a fade-out on stop. Returns true on success; a negative `ms` is refused.

seek_ms fn

seek_ms(src, ms) -> bool

src: ptr, ms: long

Seek to `ms` milliseconds from the start (clamped to [0, duration]). Returns true on success. Keeps the play/pause state.

position_ms fn

position_ms(src) -> long

src: ptr

The current play position in milliseconds — poll this from a UI tick to drive a seek slider. (Milliseconds rather than Duration because the language has no Duration-from-ns constructor yet; a Duration accessor is a clean later addition.)

duration_ms fn

duration_ms(src) -> long

src: ptr

The total length of the source in milliseconds.

channels fn

channels(src) -> int

src: ptr

sample_rate fn

sample_rate(src) -> int

src: ptr

played_frames fn

played_frames(src) -> long

src: ptr

Frames of the SOURCE the mixer has consumed since load — across loops, and in source frames regardless of pitch. Under `open_headless` this is exactly what `render` pulled, which lets a test hold playback to a number.

group_new fn

group_new() -> ptr!

Create a group (a bus: music, effects, ambience, voice) with its own volume. Sources join it with `set_group`. A group must outlive the sources routed through it: reassign or unload them before `group_free`. Returns (group, "") on success, (null, reason) on failure.

group_free fn

group_free(group)

group: ptr

Release a group. Sources still routed through it fall silent until reassigned, so unload or `set_group` them first.

group_volume fn

group_volume(group, v) -> bool

group: ptr, v: float

Set the group's volume in [0.0, 1.0] (clamped); it multiplies each member's own volume. Returns true on success.

group_get_volume fn

group_get_volume(group) -> float

group: ptr

The group's current volume in [0.0, 1.0].

set_group fn

set_group(src, group) -> bool

src: ptr, group: ptr

Route `src` through `group`; `null` routes it straight to the output again. A source is in one group at a time. Returns true on success.

stream_open fn

stream_open(sample_rate, channels, format, capacity_frames) -> ptr!

sample_rate: int, channels: int, format: int, capacity_frames: int

Open a QUEUE source: a bounded ring of `capacity_frames` frames of PCM in `format` (a FORMAT_* constant) that the program pushes into with `stream_push` while the source plays. Reads past what has been pushed play silence and count as underruns rather than ending the source, so a producer that falls behind recovers instead of stopping. A stream cannot seek or loop and reports a duration of 0; `position_ms` is the audio it has consumed. Returns (src, "") on success, (null, reason) on failure.

stream_push fn

stream_push(src, data, length) -> int!

src: ptr, data: string, length: int

Push `length` bytes of interleaved samples into a queue source. `length` must be a whole number of frames. Returns (frames_accepted, ""): fewer than offered when the ring is full — push the rest later — or (-1, reason) for a bad argument or a source that is not a stream.

stream_queued fn

stream_queued(src) -> int

src: ptr

Frames pushed and not yet consumed by the mixer (0 for a non-stream).

stream_capacity fn

stream_capacity(src) -> int

src: ptr

The ring's capacity in frames (0 for a non-stream). Free space is `stream_capacity(src) - stream_queued(src)`.

stream_underruns fn

stream_underruns(src) -> long

src: ptr

Frames of silence the mixer substituted because the ring was empty. A producer keeping up holds this at 0; a headless test can assert it.

render fn

render(frames) -> int

frames: int

Mix `frames` frames of output through the headless engine and keep the block for `rendered_peak` / `rendered_sample`. Returns the number of frames rendered: 0 on a real-device or null-backend engine (use `open_headless`), or for a block over 4,194,304 frames.

rendered_peak fn

rendered_peak(channel) -> float

channel: int

The largest absolute sample on `channel` in the last rendered block, in [0.0, 1.0] for an unclipped mix. The one-line "held to a number" check: a mono clip of constant sample 0.125 at pan 0 renders a peak of 0.125 * cos(pi/4) in each channel.

rendered_sample fn

rendered_sample(frame, channel) -> float

frame: int, channel: int

One sample of the last rendered block, or 0.0 out of range.

unload fn

unload(src)

src: ptr

Release a source. After this the pointer is invalid.
