parse fn

parse(data) -> ptr!

data: string

Parse a buffer expected to hold EXACTLY one complete value. Returns the value on success, or errors (`ptr!`) on incomplete/malformed/trailing-garbage. Use parse_prefix for a stream where more frames follow.

parse_prefix fn

parse_prefix(data) -> (ptr, int, string)

data: byte[]

Parse ONE value from the front of `data`, a byte[] whose length travels with it (#2301): a socket reader passes the bytes it has buffered so far, e.g. `bytes.view(buf)`. Parsing borrows `data` only for the call; every payload in the returned tree is an owned copy. Returns (value, consumed, "") on success — consumed bytes were used, the rest is the next frame(s); free the value with free_value. (null, 0, "") INCOMPLETE — not enough bytes yet; read more and retry with the fuller buffer. Distinct from error. (null, 0, msg) MALFORMED — a protocol error; msg says why. This is the resumable entry point for a socket reader.
