actors

std.actors — process-global name → actor_ref registry.

import std.actors

register fn

register(name, ref)

name: string, ref: actor_ref

Bind `name` → `ref`. Overwrites any prior binding of the same name (no error). The name is duplicated internally; the actor_ref is stored as-is.

whereis fn

whereis(name) -> actor_ref

name: string

Look up by name. Returns the registered actor_ref, or null (when cast to actor_ref) if no binding exists. Pattern: spawn at startup, register with a stable name, look up from any context (including from inside C-callback handlers that can't take an Aether-typed parameter).

unregister fn

unregister(name) -> int

name: string

Remove a binding. Returns 1 if a binding was removed, 0 if `name` wasn't registered.

is_registered fn

is_registered(name) -> int

name: string

1 if `name` is bound, 0 otherwise.

registry_size fn

registry_size() -> int

Number of currently-registered names. Mostly for tests / debug.

registry_clear fn

registry_clear()

Wipe all bindings. Tests use this for isolation.

monitor fn

monitor(ref) -> int

ref: actor_ref

From a handler: one Down to this actor when `ref` ends, at once if it has ended already. Returns the monitor's id, for demonitor.

demonitor fn

demonitor(id)

id: int

From a handler: no Down of monitor `id` is handled after this, one already on its way included.

kill fn

kill(ref)

ref: actor_ref

Ends `ref` with "killed" once its current handler, if one is running, returns. Its queued messages are dropped and counted (dead_sends), an ask it is waiting in ends at once, and its watchers get Down. From anywhere; a dead actor is not killed twice.

stop fn

stop()

From a handler: this actor ends with "normal" when the handler returns.

dead_sends fn

dead_sends() -> long

Messages a panicked, killed or stopped actor did not handle: queued at its death or sent to it after, each released and counted once.

full_drops fn

full_drops(ref) -> long

ref: actor_ref

Plain sends (`!`) to `ref` dropped because its mailbox was full: an actor declared `@mailbox(bound: N)` takes at most N messages it has not handled yet. try_send(ref, Msg {...}) says "the mailbox is full" instead, and an ask fails with it; neither is counted here.

link fn

link(ref)

ref: actor_ref

From a handler: this actor and `ref` are linked, both ways. When either ends, the other ends too, with the same reason (a panic's message, or "killed"), unless that reason is "normal", which ends nothing; one that traps exits gets a Down instead and lives on. Linked to an actor that has ended already, this actor takes its death at once.

unlink fn

unlink(ref)

ref: actor_ref

From a handler: the link with `ref` goes, both ways. A death already taken by it stays taken.

trap_exits fn

trap_exits(on)

on: bool

From a handler: a linked actor's death reaches this actor as a Down (its id 0, never dropped by demonitor) instead of ending it, while `on`.

rebirth_begin fn

rebirth_begin(ref) -> int

ref: actor_ref

1 when `ref` is claimed for a restart on this thread: it has ended, its death is finalized and no message of it is in flight. 0 when not yet (try again soon), -1 when it cannot be (it is alive, released, or one a C host registered).

rebirth_end fn

rebirth_end(ref) -> int

ref: actor_ref

1 when `ref` is alive again. 0 when the factory spawned no actor of its type, or panicked first: the restart is undone and `ref` stays ended, "the restart failed".

incarnation fn

incarnation(ref) -> int

ref: actor_ref

How many times `ref` was restarted in place: 0 for the actor spawned.
