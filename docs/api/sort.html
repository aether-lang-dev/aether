sort

std.sort — in-place ascending sort and binary search over slices: `int[]`, `long[]`, `float[]` and `string[]`.

int_search fn

int_search(xs, x) -> int

xs: int[], x: int

Binary search a SORTED `xs` for `x`: the index of the first element not ordered before `x`, which is `x`'s index when present and otherwise where it would be inserted to keep `xs` sorted (`xs.len` when every element sorts before it). C3's binarysearch contract.

ints_by(xs, cmp, int) -> int)
