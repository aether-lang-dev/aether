yaml

std.yaml - YAML Module Import with: import std.yaml Parses and serializes YAML per YAML 1.2 using libfyaml.

import std.yaml

parse fn

parse(yaml_str) -> ptr!

yaml_str: string

Parse a YAML string. Returns (document_ptr, "") on success, (null, error) on failure. Caller owns the returned document and must free it using yaml.free.

free fn

free(doc)

doc: ptr

Free a parsed YAML document.

root fn

root(doc) -> ptr

doc: ptr

Get the root node of the parsed document.

type fn

type(node) -> int

node: ptr

Get the type of a node (returns YAML_SCALAR, YAML_SEQUENCE, YAML_MAPPING, or 0 if null).

get_scalar fn

get_scalar(node) -> string!

node: ptr

Read the scalar string value out of a YAML node. Returns (scalar_str, "") on success, ("", error) if node is not a scalar.

sequence_size fn

sequence_size(node) -> int

node: ptr

Get the size of a sequence node. Returns -1 if not a sequence.

sequence_get fn

sequence_get(node, index) -> ptr

node: ptr, index: int

Get the item node at the given index in a sequence node. Returns null if index out of bounds.

mapping_size fn

mapping_size(node) -> int

node: ptr

Get the number of key-value pairs in a mapping node. Returns -1 if not a mapping.

mapping_get_key fn

mapping_get_key(node, index) -> ptr

node: ptr, index: int

Get the key node at the given index in a mapping node. Returns null if index out of bounds.

mapping_get_value fn

mapping_get_value(node, index) -> ptr

node: ptr, index: int

Get the value node at the given index in a mapping node. Returns null if index out of bounds.

mapping_lookup fn

mapping_lookup(node, key) -> ptr

node: ptr, key: string

Look up a value node by a string key in a mapping node. Returns null if not found or not a mapping.

emit_node fn

emit_node(node) -> string!

node: ptr

Emit a YAML node to a string representation.

emit_document fn

emit_document(doc) -> string!

doc: ptr

Emit a YAML document to a string representation.
