coef: long, exp: int

coef * 10^exp, e.g. new(1234, -2) is 12.34 and new(5, 3) is 5000.

from_string fn

from_string(s) -> (ptr, string)

s: string

Parse decimal text: an optional sign, digits with at most one '.', and an optional exponent part ("1.5e-3", "2E10"). "-.5" and "5." are accepted as the Go library accepts them; whitespace, underscores, "Inf" and "NaN" are not. The exponent of the result is exactly the number of fractional digits written (adjusted by any e-part), so from_string("1.50") keeps the trailing zero until something rounds or rescales it.

rescale fn

rescale(d, exp) -> ptr

d: ptr, exp: int

The same value expressed with exponent `exp`. Lowering the exponent is exact (the coefficient gains zeros); raising it truncates toward zero, so rescale(1.29, -1) is 1.2 and rescale(-1.29, -1) is -1.2. The rounding functions are all built on this truncation.
